# Git Conventions

Personal preferences for branches, commits, and repository workflow.

## Branch Naming

- Use English: `<issue-number>-<type>-<short-description>`, e.g. `74-fix-taxamount-auto-assign`.
- Do not use pinyin or Chinese in branch names.
- Do not infer pinyin/transliteration from repository history; existing pinyin branches are legacy, not a convention to follow.
- Still respect the platform's issue-association rule (e.g. GitLab branches start with the issue IID, no `/`).

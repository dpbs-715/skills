# Agent Routing

Before substantive work, assess whether the task needs a repository role's
specialist judgment or methods. Skip role loading for trivial edits and unrelated
work.

When a role is needed, read and follow
`{{REPO_ROOT}}/generated/agent-routing/SKILL.md` before selecting or loading it.
That skill owns role selection, configuration loading, direct application,
delegation, and reporting. Respect the user's request to work directly or avoid
subagents.

Reuse configuration already loaded in this agent; links back to loaded rules or
skills do not restart selection or loading. Reload when the source changes or
the instructions are no longer available in context.
